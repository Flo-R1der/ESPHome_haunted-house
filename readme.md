



## Pinout

| Pin    | Target       | Note               |
| ------ | ------------ | ------------------ |
| GPIO1  | LD2410C RX   | Radar-Sensor       |
| GPIO3  | LD2410C TX   | Radar-Sensor       |
| GPIO5  | Power-LED 2  | Flash              |
| GPIO13 | Power-LED 1  | Flash              |
| GPIO15 | 5V Fan       |                    |
| GPIO16 | DF-Player TX |                    |
| GPIO17 | DF-Player RX |                    |
| GPIO18 | Power-LED 4  | Flash              |
| GPIO19 | Power-LED 3  | Flash              |
| GPIO21 | BH1750 SDA   |                    |
| GPIO22 | BH1750 SCL   |                    |
| GPIO23 | WS2812 Data  | RGB LED-Strip      |
| GPIO26 | Power-LED 5  | Flash              |
| GPIO36 | Red Buzzer   | _(only Input Pin)_ |

> GPIO7-11 are not allowed to be used (SPI bus for flash memory)  
> GPIO34-36+39 are input only pins
